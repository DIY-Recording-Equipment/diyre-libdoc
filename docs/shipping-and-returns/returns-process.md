It's ok to change your mind. You can return unopened kits and as-new assembled units within 30 days of when you received you order for a refund, minus the shipping costs. Please visit the [returns portal](https://account.diyrecordingequipment.com) to request a return.

Unfortunately, we can't accept returns after you've started soldering. Once the iron gets hot, you are the manufacturer.

Note that we can only send returns to the original payment method.

  

## Step-by-step Process  for Requesting a Return

  

1. Go to the [Customer Account page](https://account.diyrecordingequipment.com).
2. Sign in to your account:
   1. In the "Email" field, enter your email address, and then click "Continue".
   2. In your email account, open the email sent from our store and copy the six-digit verification code included in the email.
   3. Go back to the online store, and then enter a six-digit verification code.
3. Click "Request return" for the order that you want to submit the return for.
4. If your order has more than one item, then select the items that you want to return.
5. Select a return reason and add a note for the store.
6. Click "Request return".

  

If your return request is approved and requires shipping, then you receive an email with shipping instructions and a return shipping label. After the product is returned, you receive a refund.
