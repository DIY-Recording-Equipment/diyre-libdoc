## The CR1 diode has a black stripe instead of the yellow one shown in the guide {.step}

Diode marking varies by manufacturer and batch, so a black stripe in place of yellow is a labeling inconsistency, not a different part. Align whichever colored stripe you have with the white line on the PCB, the same as you would with the documented yellow-stripe part.

## A capacitor's color or printed value doesn't match what you expected {.step}

Capacitor colors can vary between batches (yellow versus blue, for example), and some printed values are in pF rather than the more familiar farad-based units you might expect (a value like "22k" that's actually pF, not ohms). Check the value itself against the sorting guide's value-to-color mapping before assuming a part is missing or wrong.
