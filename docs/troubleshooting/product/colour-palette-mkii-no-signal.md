If your Palette is not passing a signal, please check the following:

1. Empty Colour slots: make sure that no empty Colour slots are engaged. If a Colour slot is empty, engaging it will mute the signal.
2. Signal path: confirm your routing by patching a cable directly from the output of your interface to the input of your interface.
3. 500-series rack: if possible, test another module in the same slot the Palette was in, and try the Palette in a different slot
4. IC positions: Double check that all ICs are in the correct locations as show below.

   ![](https://s3.amazonaws.com/helpscout.net/docs/assets/5b2130d82c7d3a0fa9a2f0bc/images/5c17e0462c7d3a31944f334b/file-sAb6OJevmV.png)
5. IC orientation: Make sure that the notches on the bodies of the ICs match the notches in the silk screen on the circuit board.
