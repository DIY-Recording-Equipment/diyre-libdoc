**Note:** Mods are not supported! Once you start modding, we cannot offer troubleshooting support. Make sure your unit is working in the stock configuration before adding any mods.

The amount of MAKE-UP gain is set by the resistor R1\_CB. With the stock value of 4.7k the maximum gain is 25dB. You can increase/decrease the maximum gain by increasing/decreasing the value of R1\_CB. The absolute maximum gain with R1\_CB jumpered (0 Ohms) is 30dB.
